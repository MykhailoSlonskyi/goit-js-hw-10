# Sunny Coffee — ДЗ №10

Панель бариста на JavaScript і Vite. Кожне замовлення одразу з’являється в
журналі, а після часу приготування оновлюється на «готове» або «скасовано».
Кілька замовлень обробляються одночасно.

- [Репозиторій](https://github.com/MykhailoSlonskyi/goit-js-hw-10)
- [Жива сторінка](https://MykhailoSlonskyi.github.io/goit-js-hw-10/)

## Локальний запуск

```sh
npm ci
npm run dev
```

## Перевірка та збірка

```sh
npm run format:check
npm run build
npm run preview
```

Проєкт підготовлено на основі
[goit-js-hw-template](https://github.com/goitacademy/goit-js-hw-template). Під
час деплою Vite бере шлях сайту з назви репозиторію. У Settings → Pages потрібно
обрати Source → GitHub Actions.
